# Contributor license agreement signers

Each line below is a signature record of the [Portifact Individual Contributor License Agreement](cla.md): the GitHub login and numeric account ID, the full legal name, the date, and the version and digest of the agreement signed. The signature itself is the signer's statement in a comment on their pull request ([contributing.md](contributing.md)); this file is an index of recorded agreements, not independent proof that the named person signed. Append your record at the end of the list in your first pull request and change nothing else. The `cla` check refuses a pull request whose contributors have not signed, a record added for an account that did not confirm it with its own statement, and any other change to this file.
