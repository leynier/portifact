# Contributor license agreement signers

Each line below indexes a signature of the [Portifact Individual Contributor License Agreement](cla.md): the GitHub login and numeric account ID, the full legal name, the date and the statement of the version signed. The signature itself is the signer's comment on their pull request ([contributing.md](contributing.md)); this file is an index of recorded agreements, not independent proof that the named person signed. Add your line in your first pull request, at the end of the list. The `cla` check refuses a pull request whose contributors have not signed, a line added for an account that did not confirm it, and any change to an existing line.
